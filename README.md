# 🐱 Limbo Cats

**Limbo Cats** — это мини-игра на внимательность и зрительную память, вдохновлённая легендарным уровнем *Limbo* из ритм-платформера *Geometry Dash*. 

В отличие от оригинальной игры (где нужно угадывать клавиши), здесь вам предстоит следить за окнами с котиками. Игра проверяет вашу способность удерживать внимание на объекте, когда вокруг происходит хаос.

---

## 🎮 Геймплей

1. **Старт:** На экране появляются 8 абсолютно одинаковых окон с котиками (🐱).
2. **Запоминание:** Одно из окон подсвечивается **зелёным** цветом изнутри. У вас есть 1.5 секунды, чтобы запомнить его положение.
3. **Перемешивание:** Окна начинают **плавно и быстро двигаться** по экрану. Всего происходит 5 циклов перемешивания, во время которых окна меняются местами, описывая круги.
4. **Угадывание:** Как только движение прекращается, все котики становятся **разноцветными** (каждое окно получает свой уникальный цвет). Вам нужно кликнуть по тому окну, которое изначально было зелёным.
5. **Результат:** 
   * Если вы угадали — окно загорается зелёным, появляется сообщение «Молодец!».
   * Если ошиблись — ваше окно становится красным, а правильное подсвечивается зелёным, чтобы вы увидели, где оно было. Игра завершается.

**Важно:** Игра **одноразовая**. После клика раунд не перезапускается. Чтобы сыграть ещё раз, нужно запустить игру заново (при этом расстановка и цвета будут совершенно другими).

## ✨ Особенности

*   **Оригинальный интерфейс Windows:** Игра использует настоящие системные окна Windows (`Toplevel`), а не кастомную отрисовку. У каждого котика есть заголовок и кнопка закрытия.
*   **Плавная анимация:** Перемешивание происходит с частотой **60 FPS** с использованием алгоритма линейной интерполяции (LERP), поэтому окна двигаются плавно, а не телепортируются.
*   **Встроенная музыка:** Мелодия *Nokia Arabic Ringstone* упакована внутрь `.exe` файла и воспроизводится зацикленно. Никаких внешних плееров или скачивания аудио не требуется.
*   **Полная рандомизация:** При каждом запуске игра случайно выбирает:
   * Угол поворота и радиус круга, по которому стоят котики.
   * Цвета для каждого окна.
   * Окно, которое будет правильным.
*   **Безопасность:** Игра не требует прав администратора и не вносит изменений в систему (кроме создания временного `.wav` файла для музыки, который удаляется при выходе).
